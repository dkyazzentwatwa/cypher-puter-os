## Overview

Cardputer Game Station Emulators is packaged as a standalone emulator launcher
app in the Cypher OS SD catalog. ROM and save files stay on the SD card outside
the Cypher OS app binary folder.

## Return To Cypher OS

Use `Fn+Del` when you are in the launcher/menu side of the app. Quit or save
active gameplay first so emulator state is not interrupted mid-frame.
