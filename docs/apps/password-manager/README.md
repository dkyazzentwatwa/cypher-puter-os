# Password Manager

## Cypher OS Package

| Field | Value |
| --- | --- |
| Catalog slug | `password-manager` |
| SD binary | `/cypher-puter/apps/password-manager.bin` |
| Source repo | https://github.com/dkyazzentwatwa/cardputer-app-bundle |
| Local source path | `/Users/cypher/Documents/GitHub/new-cardputer-apps/Password-Manager` |
| Build profile | `cardputer` |
| Extra SD paths | `/vaults/` |
| Return path | Choose Cypher OS from the no-vault home menu. |
| Package note | Built from the public `cardputer-app-bundle` repo while the default local checkout remains `../new-cardputer-apps`. |

## Overview

Password Manager is packaged as an offline Cardputer vault app. Cypher OS only
ships the app binary; vault files stay on the SD card.

## Return To Cypher OS

From the no-vault home menu, choose `Cypher OS` to set the one-shot launcher
return flag and restart.
