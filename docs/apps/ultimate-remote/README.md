| Field | Value |
| --- | --- |

## Overview

Ultimate Remote is packaged as a Cardputer ADV remote-control utility in the
Cypher OS SD catalog.

## Return To Cypher OS

Use the main menu entry labeled `CYPHER OS` to set the launcher return flag and
restart into Cypher OS.
